# Troubleshooting journal

Create one Markdown file per failure scenario. Record the symptoms, environment, diagnostic commands, root cause, fix, and prevention steps. Redact tokens, identifying information, and IP addresses when appropriate.

Example scenarios: a Cloud Run container listening on the wrong port; a GKE Pod stuck in `ImagePullBackOff`; an unreachable VM due to firewall rules; insufficient IAM permissions in GitHub Actions.
