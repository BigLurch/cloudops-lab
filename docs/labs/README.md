# Hands-on labs

Save separate notes, commands, and verification evidence for each lab here. Suggested first labs:

- `lab-01-cli.md`: inspect the active configuration, project, and identity.
- `lab-02-networking.md`: investigate firewall and routing issues.
- `lab-03-deployment-comparison.md`: compare the same API on Compute Engine, Cloud Run, and GKE.

Use the [lab template](../templates/lab-template.md). Always remove temporary GCP resources after completing the exercise.
