# Architecture Decision Records (ADRs)

Create a file named `0001-<decision>.md` for each significant design decision. Use this structure:

- **Context:** What problem are we solving?
- **Decision:** What did we choose?
- **Alternatives:** What did we reject, and why?
- **Consequences:** What trade-offs or disadvantages follow?
- **Revisit when:** Under what conditions should we reconsider?

Suggested first ADR: **Why we start with Compute Engine and Cloud Run before GKE.**
